This folder contains different types of images to test our application.

Color Check Images - contains images with different colors in different formats

Neuroblastoma Cells Images - contains two types of images: SK-N-DZ (20x) and IS_3 (10x)

Plain Cells - contains all the other types of cell images that are not special in any way

Spheroid Tracking Sequence - contains a series of images for spheroid tracking. Can be tested using tracker plugin

Stained Nuclei Images - contains images of stained (dead) nuclei
